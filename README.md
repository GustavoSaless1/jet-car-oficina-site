# Jet Car Oficina Mecânica

Site institucional desenvolvido para a Jet Car, oficina mecânica localizada em São Mateus, São Paulo.

## Sobre o projeto

O projeto apresenta os serviços da oficina, registros reais do trabalho, horários e localização. Também oferece um fluxo de orçamento que prepara a mensagem do cliente e direciona a conversa para o WhatsApp.

## Principais recursos

- Interface responsiva para celular, tablet e desktop
- Formulário que gera uma mensagem personalizada para o WhatsApp
- Galeria e vídeos reais da oficina
- Integração com Google Maps e Instagram
- Menu móvel e componentes acessíveis
- SEO com metadados, Open Graph, sitemap, robots.txt e dados estruturados Schema.org
- Otimização de imagens e carregamento de mídia

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript
- Git e GitHub
